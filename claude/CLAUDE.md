## 人間用の出力にはビジュアライズを使う

- 人間は長い標準出力を読むことができません
- 人間はたとえ構造化されていたとしても長いマークダウンファイルを読むことができません
- 積極的にビジュアライズしてください

## AskUserQuestionを使いたくなったら

「どの手法か」「どうすべきか」「これは何をすべきか」で迷ってユーザーに質問したくなった場合、
答えが、何かを実行することで観察できる事実（振る舞い、タイミング、レイアウト、出力、パフォーマンス等）なら、それは人間が答えるものではない
意思決定のための実験、または証拠集めを行い、その結果で決めること
質問はどの実験でも決着しない、本当の製品判断や好みの判断のために取っておくこと
質問するのは回り道すぎる。使い捨ての試作の方がたいてい速く答えを出し、反応すべき結果を返す

## 独自の専門用語や略語は使わず、一般的な用語に置き換えて
特に対応する日本語がないものを訳すのはやめて
例えばSource of Truthを正本と訳するようなこと


## GitHub に画像・動画を載せるとき

`gh pr comment` / `gh issue comment` の `--attach <file>` でアップロードする。本文の `![alt](./a.png)` はアップロード先の URL に書き換わる。画像を repo に commit しない
