description: 直近1週間のレビューコメントを見て、コンテキスト情報を改善する
---

## Workflow

- 対象リポジトリ: 実行時のカレントディレクトリのリポジトリ
- 過去7日以内にマージされたPRのレビューコメントを取得する（`gh pr list --search "is:merged merged:>=<7日前>"`）
- レビューコメントをもとに改善できそうなコンテキスト情報を整理する
  - 各観点ごとにsub-agentを起動する
  - 観点
    - CLAUDE.md
    - rules
    - skill
    - code comment（レビューで指摘された箇所に限定。指摘内容の一般化・全体適用はしない）
    - test（レビューで指摘された箇所に限定。指摘内容の一般化・全体適用はしない）
    - detekt rules
  - 増やすことだけでなく、減らすことも検討する
- コンテキスト情報を改善する
  - sub-agent(Sonnet)を起動して並列作業する
  - 各sub-agentは対象ファイルを直接編集する
  - 完了後、変更一覧と根拠（該当レビューコメントのURL）をレポートする

## Scope

- feedback memory（会話内でユーザーから直接得た指摘の保存）とは役割が異なる。本skillはPRレビューコメントを起点にリポジトリのdocs/コードを更新する
- 「実態として暗黙的に守られているルールの明文化・記載漏れの追記」と「議論・意思決定が必要な内容の追記」を分ける
  - 「実態として暗黙的に守られているルールの明文化・記載漏れの追記」の方を採用する
